# Icons Directory

This directory contains icon files for the applications.

## Required Icons:

- sales.png - Icon for Sales Analyzer app
- hr.png - Icon for HR Insights app
- finance.png - Icon for Finance Tracker app
- inventory.png - Icon for Inventory Control app
- customers.png - Icon for Customer Reports app

## Note:
Currently, the application uses emoji icons as fallback (📊, 👥, 💰, 📦, 👤).
You can replace these with actual PNG/SVG icon files by placing them in this directory.

## Icon Specifications:
- Format: PNG or SVG
- Recommended size: 64x64 pixels
- Background: Transparent
