# AI-Powered SQL Query Assistant Platform
### Natural Language → SQL → Insights

---

## Executive Summary

The AI-Powered SQL Query Assistant Platform provides a smart and user‑friendly interface that allows employees to request information in natural language. The system understands the request, retrieves data from the selected database, and returns meaningful ready‑to‑use insights such as reports, charts, summaries, tables, or email drafts.

This solution reduces IT workload, accelerates decision‑making, and centralizes secure access to organizational data.

---

## Application Overview

### User Interface

A simple, modern one‑page interface featuring:
- A sidebar showing all applications assigned to the logged‑in user.
- A recent activity panel showing the user’s last 10 requests.
- A form with two required fields: **Subject** and **Details**.

### Workflow Summary

User enters a request →  
System understands the meaning →  
AI generates the correct SQL →  
System retrieves data from Oracle, SQL Server, or MySQL →  
AI produces the final business‑ready output →  
User receives immediate insights.

- .NET Core Web API  
- Oracle 19c (primary database)
